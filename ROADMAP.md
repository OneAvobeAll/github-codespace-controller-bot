# Project Roadmap

## Vision

Make GitHub Codespaces management accessible through a Telegram bot interface.

---

## Current Features (v1.0.0)

- Create and manage applications
- GitHub repository configuration
- Environment variables management
- Custom build/start commands
- Docker implementation option
- Codespace start/stop control
- Multiple GitHub token management
- Basic billing information
- MongoDB integration
- Docker Compose setup

---

## Planned Features

### v1.1.0 (Q4 2024)
- Web dashboard for app management

- Improved billing with cost breakdown
- Usage graphs and analytics

### v1.2.0 (Q1 2025)
- Team collaboration features

### v1.3.0 (Q2 2025)

### v2.0.0 (Future)
